# SC 234 Cabang Caringin

Website full stack tema black metalik (Vercel + Upstash Redis).

- Website: `/`
- Admin: `/admin`

## Deploy
1. Push repo ini ke GitHub, lalu Import di vercel.com (nama project: `sc234-cabang-caringin`).
2. Storage > Create > Upstash Redis > Connect Project.
3. Settings > Environment Variables: `ADMIN_USER`, `ADMIN_PASS`, `SECRET` (teks acak panjang).
4. Redeploy.
